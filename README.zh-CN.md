# LiveCamera-LBS

**LiveCamera-LBS** 是一个 Android 实景巡礼匹配助手。  
用户可以拍摄或上传现实场景图片，让多模态 AI 理解画面内容，再进入动漫圣地巡礼、国内旅行识别、地图导航和本地巡礼日记等流程。

当前版本：**v1.5.0**  

## 功能板块

| 模块 | 说明 |

| **动漫圣地巡礼匹配**<br><sub>作品、点位与现实取景线索</sub> | **分类：**动漫巡礼<br><br>**适合：**车站、学校、桥、海边、展馆、神社、商业街、街道路口等巡礼参考图。<br><br>App 会先识别可能作品，再让用户选择或手动纠正作品名。随后系统会把 **选定作品 + 当前图片** 再次交给 AI 匹配，结合 Anitabi 点位候选排序，最后由用户确认巡礼地点。 |

## 使用流程

1. 打开 App。
2. 拍照或从相册选择图片。
3. 点击 **开始识别**。
4. 查看 AI 给出的当前主结果。
5. 如果是动漫巡礼，可以选择 AI 候选作品，或手动输入正确作品名。
6. 系统会把“选定作品 + 当前图片”再次交给 AI 匹配。
7. 查看主地点和其他候选巡礼地点。
8. 确认后保存到巡礼日记。
9. 在巡礼日记中查看详情、删除记录或导出数据。

## 识别模式

### 智能识别

默认入口。系统根据图片内容判断更适合动漫巡礼还是国内旅行。

### 动漫巡礼

优先保留动漫巡礼链路。即使画面里有真实建筑，也不会直接当作国内旅行景点处理。用户选择或输入的作品名会作为约束，让 AI 再次结合当前图片匹配巡礼地点。

### 国内旅行

面向中国境内景点、城市地标、建筑和自然风光。该模式会走国内旅行结果链路，不调用动漫作品或巡礼点 API。
