**LiveCamera-LBS** is an Android scene-matching assistant for real-world anime pilgrimage and travel discovery.  
Take or upload a photo, let multimodal AI understand the scene, then continue through anime pilgrimage matching, domestic travel recognition, map navigation, and a local check-in diary.

Current version: **v1.5.0**  
[Download latest APK](https://github.com/ayumu317/livecamera/releases/latest)

## Feature Blocks

| Module | What It Does |
| --- | --- |
| **Smart Scene Recognition**<br><sub>Default entry / AI routing</sub> | **Category:** multimodal scene understanding<br><br>**Best for:** users who just want to upload a photo and get a useful result without choosing a mode first.<br><br>LiveCamera-LBS analyzes the image and routes it into either anime pilgrimage matching or domestic travel recognition. It is designed to avoid forcing users into a technical workflow before the app understands the scene. |
| **Anime Pilgrimage Matching**<br><sub>Works, spots, and real-world references</sub> | **Category:** anime pilgrimage<br><br>**Best for:** stations, schools, bridges, seaside views, exhibition halls, shrines, shopping streets, and other pilgrimage-style reference photos.<br><br>The app first identifies possible anime works, then lets the user choose or manually correct the work title. After that, it sends **the selected work + the current image** back to AI for a second pass, ranks Anitabi spot candidates, and lets the user choose the final pilgrimage spot. |
| **Domestic Travel Recognition**<br><sub>Chinese landmarks and travel scenes</sub> | **Category:** travel recognition<br><br>**Best for:** Chinese landmarks, city architecture, scenic areas, natural landscapes, and tourist photos.<br><br>When domestic travel is selected or detected, the app focuses on place recognition, travel-oriented descriptions, search results, and map navigation without entering the anime API workflow. |
| **Candidate Spot Review**<br><sub>Confirm before saving</sub> | **Category:** result control<br><br>**Best for:** scenes where AI or database results may have multiple possible matches.<br><br>The app shows a main result first, then keeps other possible pilgrimage spots available under "change result". A record is saved only after the current result is confirmed, reducing mismatches between the visible result and diary data. |
| **Pilgrimage Diary**<br><sub>Local records and export</sub> | **Category:** personal archive<br><br>**Best for:** keeping track of visited or matched scenes.<br><br>Users can save check-ins, open record details, delete entries, and export diary data as JSON or TXT. Diary records are stored locally through Room. |
| **Settings & Guide**<br><sub>Customization and onboarding</sub> | **Category:** app configuration<br><br>**Best for:** adjusting the app to personal usage habits.<br><br>The settings page includes default recognition mode, image preview behavior, post-save action, color theme options, and a feature guide that explains the upload-and-recognition workflow. |

## Workflow

1. Open the app.
2. Take a photo or choose one from the gallery.
3. Tap **Start Recognition**.
4. Review the main result generated by AI.
5. For anime pilgrimage, choose an AI-suggested work or enter the correct work name manually.
6. Let AI rematch the uploaded image with the selected work.
7. Review the main spot and optional candidate spots.
8. Save the confirmed result to the pilgrimage diary.
9. Open the diary to view details, delete records, or export data.

## Recognition Modes

### Smart Recognition

The default entry. The app decides whether the uploaded image is more suitable for anime pilgrimage or domestic travel.

### Anime Pilgrimage

Prioritizes anime pilgrimage logic. Even if the image contains real buildings, the app does not immediately treat it as a domestic travel landmark. The selected or manually entered work title is used as an AI constraint for a second image-based match.

### Domestic Travel

Focuses on Chinese landmarks, city icons, architecture, and natural scenery. This mode uses the domestic travel result path and avoids anime work or pilgrimage spot APIs.
